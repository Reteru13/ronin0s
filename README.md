# Ronin0s

**A local-first mushroom cultivation journal and operations workspace.**

## Download Ronin0s for Windows

**[Download the latest Windows version](https://github.com/Reteru13/ronin0s/releases/latest)**

Download the ZIP, extract it to a writable folder, and run `RoninJournal.exe`.
Ronin0s stores records locally on the computer and does not require an account or
cloud service.

> The Windows download is published from the repository's **Releases** page.
> If you are viewing the source only, choose **Releases** in the right-hand
> sidebar and open the latest release.

## What is included

- Daily journal and documentation scoring
- Inventory tracking
- Photo records and captions
- Reference library
- Culture family tree and mycelium lineage
- Genetics observations
- Notebook workspace
- Local backup and restore
- Browser demo and desktop application

## Browser demo

To try the browser version, open [`index.html`](./index.html) in a modern browser.
Browser data is stored separately in that browser's local storage.

## Source projects

- [`RoninJournal/`](./RoninJournal/) contains the Windows desktop application.
- The root JavaScript and CSS files make up the browser demo.

## Data and privacy

Ronin0s is local-first. Desktop records and exported backups may contain
private business notes and photographs. Protect the Windows account, browser
profile, application data folder, and backup files.

See [`SECURITY.md`](./SECURITY.md) for security limitations and vulnerability
reporting.
