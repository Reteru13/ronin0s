Prompt #2: Dynamic Substrate Engine

Calculates carbon, nitrogen, and hydration using wood-based nutrient inputs.

SYSTEM CONTEXT: You are an expert mycology biochemical engineer and frontend developer.

TASK:
Build a JavaScript module for calculating substrate Carbon-to-Nitrogen ratios and field capacity.

INPUTS:
- Sawdust: 50% carbon, 0.1% nitrogen
- Soy hulls: 45% carbon, 4.5% nitrogen
- Wheat bran: 46% carbon, 2.5% nitrogen
- Coco coir: 48% carbon, 0.4% nitrogen

LOGIC:
1. CarbonTotal = sum(weight * carbon_percentage)
2. NitrogenTotal = sum(weight * nitrogen_percentage)
3. CNRatio = CarbonTotal / NitrogenTotal
4. Target water = totalDryWeight * 1.5

ALERTS:
- C:N < 25: high contamination risk
- 25 to 45: ideal growth range
- C:N > 45: high carbon, lower biological efficiency

OUTPUT:
Return a reactive UI with chart-driven visualization and risk messaging.
